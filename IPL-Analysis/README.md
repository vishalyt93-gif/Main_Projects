# 🏏 IPL Tournament Analysis Dashboard

## 🚀 Project Overview
Built an interactive Power BI dashboard to analyze Indian Premier League match data and provide tournament insights across team performance, player statistics, match situations, and head-to-head player matchups.

This project was created to explore cricket analytics and demonstrate data visualization, DAX calculations, and interactive dashboard design.

---

## 🎯 Project Objectives

### 📊 Tournament Overview
Analyze overall tournament performance including top run scorers, wicket takers, boundary hitters, and team standings.

### 🏆 Team Performance Analysis
Compare how teams perform in different match situations such as batting first, chasing targets, and defending totals.

### 🧠 Player Matchup Analysis
Explore batter vs bowler head-to-head performance to uncover matchup trends and player dominance.

---

## 🛠️ Tools Used
- Power BI

---

## 📌 Dashboard Features

✔️ Points Table & Team Rankings  
✔️ Highest Run Scorers & Wicket Takers  
✔️ Most Sixes & Fours Analysis  
✔️ Team Performance: Chasing vs Batting First  
✔️ Defending Scores Below 180  
✔️ Successful Chases Above 200  
✔️ Batter vs Bowler Matchup Analysis
